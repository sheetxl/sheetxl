# How To Guides

Got a job to do? Start here. Each guide picks one task and walks you through it, with code you can copy.
If you want to know *why* SheetXL works the way it does, the [Concepts](../30-concepts/overview.mdx)
section has that.

### Cells and values

- **[Read and Write Values](./10-read-and-write-values.md)**: get and set values, clear cells, and
  insert or delete rows and columns.
- **[Transform Values with IRange](./15-transform-values-with-irange.md)**: reshape, fill, and compute
  over values before writing them back.
- **[Work with Sparse Data](./20-work-with-sparse-data.md)**: visit only the cells that have something
  in them.
- **[Listen for Changes](./25-listen-for-changes.mdx)**: react when cells change, in plain TypeScript
  or with React hooks.

### Look and feel

- **[Style Cells](./30-style-cells.mdx)**: fonts, fills, borders, number formats, and finding the cells that have them.
- **[Theme the Spreadsheet](./35-theme-the-spreadsheet.md)**: match your site's colors, light and dark.
- **[Resize and Hide Rows and Columns](./40-resize-and-hide-rows-and-columns.md)**
- **[Drawing on the Grid](./55-drawing-on-the-grid.mdx)**: draw your own highlights, markers,
  and buttons on the sheet, as layers that scroll and zoom with it.

### Files

- **[Load and Save Workbooks](./45-load-and-save-workbooks.mdx)**: JSON, xlsx, CSV, from the SDK or the
  command line.
- **[Configure a Backing Store](./50-configure-a-backing-store.mdx)**: redirect where workbooks are read
  from and written to (a VS Code host, a backend, a database, …).

### Code

- **[Write a Custom Function (UDF)](./60-write-a-custom-function.md)**: add your own formula functions in
  TypeScript.
- **[Write a Runner Script](./65-write-a-runner-script.md)**: one script, run from the CLI, your own Node
  program, or an AI agent.
