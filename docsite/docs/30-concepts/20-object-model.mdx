If you know Excel, you already know the shape of SheetXL: a **workbook** holds **sheets**, a sheet holds
**cells**, and you reach the cells through a **range**. Each of those is a TypeScript interface, and this
page introduces the ones you'll use every day and how to get from one to the next.

### [ICellRange](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellRange.html)

Represents a rectangular selection of cells, allowing you to read, write, and manipulate data within
that region. Use `ICellRange` to access cell values, apply formatting, and perform operations on groups of cells.

A rectangular collection of [ICell](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICell.html)s within a [IWorksheet](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorksheet.html).

Ranges can be retrieved using either a workbook or a sheet.

```typescript
// return a range via a workbook
const rangeWB:ICellRange = workbook.getRange('Sheet1!A1:E5000');

// return the range via a sheet
const rangeSheet:ICellRange = workbook.getWorksheet('Sheet1')?.getRange('A1:E5000');

```

### [ICell](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICell.html)

Represents a single cell within a spreadsheet. It provides access to the cell's value, formatting,
and other metadata. Use `ICell` to get or set the properties of individual cells.

A single unit of data and meta data within an [ICellRange](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellRange.html),
located at a specific row and column.

Cells are always accessed via a range and can be retrieved in a few different ways.

```typescript
// returns the top/left cell
const cellTopLeft:ICell = workbook.getRange('Sheet1!A1:E5000').getCell();

// returns all cells in range as a 2D array
const cellsArray:ICell[][] = workbook.getRange('Sheet1!A1:E5000').getCells();

// iterates the cells that have content, skipping empty ones
const cellsIterator:IterableIterator<ICellRange.Entry> = workbook.getRange('Sheet1!A1:E5000').entries();
```

### [IWorksheet](https://api.sheetxl.com/modules/_sheetxl_sdk.IWorksheet.html)

Represents a collection of elements such as [ICellRange](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellRange.html),
[ITable](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ITable.html), and other elements contained within and visualized
through a [IWorksheetView](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorksheetView.html).

Sheets can be retrieved using either `getWorksheet()` or `getWorksheets()` from a workbook.

```typescript
// return a sheet via a workbook
const sheet:IWorksheet = workbook.getWorksheet('Sheet1');

// return all sheets via a workbook
const sheets:IWorksheetCollection = workbook.getWorksheets();
```

### [IWorkbook](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorkbook.html)

Represents a collection of [IWorksheet](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorksheet.html)s,
and other shared resources.

To create a workbook model simply import the `@sheetxl/sdk` package and create a new instance.

```typescript
// create a default workbook
const workbook:IWorkbook = new Workbook();
```

### [ICellStyle](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellStyle.html)

Represents the formatting applied to a cell or range of cells, including font, color, alignment,
number format, and borders.

Provides access to the combined styling information for a cell or range, including user-applied styles
and dynamic styles (e.g., from tables or conditional formatting).

```typescript
// Set the fill to theme color accent 1.
workbook.getRange('Sheet1!A1:D5000').getStyle().update({ fill: 'accent1' });
```

### [ICellRanges](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellRanges.html)

Represents a collection of [ICellRange](https://api.sheetxl.com/interfaces/_sheetxl_sdk.ICellRange.html)s.
This is useful when you need work with non-contiguous ranges as a single unit,
such as applying the same formatting or extracting data from multiple selections.

Ranges can be retrieved similar to a single range.

```typescript
const ranges:ICellRanges = workbook.getRanges('Sheet1!A1:A5000,Sheet1!C1:C5000');
// aggregate across both areas at once
const sum:number = ranges.getStats().getAggregates().sum;
```

### [IWorksheetView](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorksheetView.html)

The visual presentation of a specific sheet. It controls attributes like zoom level,
frozen rows/columns, gridlines visibility, and the active cell selection.

Use `IWorksheetView` to customize how a sheet is displayed to a specific user.

```typescript
// hide the row gridlines
workbook.getWorksheet('Sheet1').getView().setShowRowGridlines(false);
```

### [IWorkbookView](https://api.sheetxl.com/interfaces/_sheetxl_sdk.IWorkbookView.html)

The visual presentation of the entire workbook. It controls workbook-level display settings.

Use `IWorkbookView` to customize how a sheet is displayed to a specific user.

```typescript
// Hide the statusbar
workbook.getView().setShowStatusBar(false);
```
