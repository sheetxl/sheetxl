# Concepts Overview

This section is the "why" behind SheetXL. You don't need it to get something on screen (that's what
[Getting Started](../category/getting-started) is for), but a few ideas here make everything else click.

The big one: **everything in SheetXL plugs into one engine.** A workbook is a plain TypeScript object
with no UI attached. The spreadsheet UI is one way to look at it. So are a script, the command line,
and an AI agent. They all talk to the same engine, so they all get the same answers.

<EngineMapImg style={{width: '100%', maxWidth: '720px', display: 'block', margin: '1.5rem auto'}} alt={`One engine in the middle, with AI agents, your app, scripting, the command line, files, and databases all connected to it`}/>

That's why you can put several views on one workbook, build your own UI, or skip the UI entirely and
run the same code in Node, in a worker, or from an agent.

Saving works the same way. Models turn themselves into JSON; where the bytes actually go (a download,
a file, your backend) is a separate, pluggable choice.
