To empower developers with flexibility and ensure transparency,
SheetXL is built on a “mostly open source” model.

To provide everyone the freedom to easily tailor and extend the product while enabling continued
development and dedicated support SheetXL is available as a mix of MIT and commercially licensed
components; see the table below. The MIT components are available at [github](https://github.com/sheetxl/sheetxl).

<div style={{ clear: 'both' }}></div>

### Modules

| Module     | Description | License |
|------------|------|----|
| @sheetxl/sdk | Headless library for interacting with a spreadsheet.  | Commercial |
| @sheetxl/studio-mui  | A fully functional application that can be easily embedded and/or extended using Material-UI and React. | MIT |
| @sheetxl/react  | React spreadsheet components. | Commercial |
| @sheetxl/io  | Headless library for importing and exporting SheetXL, CSV, and JSON formats. | MIT |
| @sheetxl/io-xlsx  | Import and export of Excel (.xlsx) files. | Commercial |
| @sheetxl/grid-react  | A React data grid that provides basic grid capabilities.  | Commercial |
| @sheetxl/utils-mui  | A set of MUI-based components that may be used in any application setting (e.g. color picker).  | MIT |
| @sheetxl/utils-react  | A set of React-based components that may be used in any application setting (e.g. movable panel, keystroke management).  | MIT |
| @sheetxl/utils  | A set of headless utilities that may be used in any application setting. | MIT |

The full package list, with licenses, is on the [Ecosystem](./30-concepts/90-ecosystem.mdx) page.
