# API Reference

[![Logo](https://www.sheetxl.com/logo-text.svg)](https://www.sheetxl.com)

The classes, interfaces, and functions you use to build with SheetXL: create and calculate workbooks, load and save spreadsheet files, and embed the spreadsheet UI in a React app.

## Where to start

- [@sheetxl/sdk](https://api.sheetxl.com/modules/_sheetxl_sdk.html) is the primary API: workbooks, sheets, ranges, and calculation. Most code only needs this.
- [@sheetxl/primitives](https://api.sheetxl.com/modules/_sheetxl_primitives.html) holds the low-level types (`Scalar`, `IRange`) that the SDK and custom functions share.
- [@sheetxl/io](https://api.sheetxl.com/modules/_sheetxl_io.html) loads and saves workbooks.
- [@sheetxl/studio-mui](https://api.sheetxl.com/modules/_sheetxl_studio-mui.html) is the complete spreadsheet UI as a React component.

## How the packages fit together

[Our Ecosystem](https://www.sheetxl.com/docs/guides/concepts/ecosystem) describes every package, what it is for, and how it is licensed.

For guides and examples, see the [documentation](https://www.sheetxl.com/docs).
